# IT Security Policy

## Passwords and MFA

All accounts must use passwords of at least **16 characters** stored in the
company password manager, protected by **multi-factor authentication (MFA)**.
MFA is mandatory for VPN, email and cloud consoles; hardware keys (FIDO2) are
required for production access.

## Phishing and incidents

Suspicious emails must be reported with the **Report Phishing** button — never
deleted locally. If you clicked a malicious link or entered credentials on a
suspicious page: disconnect from the network and notify **security@northwind.example**
immediately; the on-call security engineer responds within **15 minutes**.

## Data handling

Customer data may be processed only on company-managed devices. Production data
must never be copied to local machines or personal cloud storage.
